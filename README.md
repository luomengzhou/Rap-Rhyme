# Rap Rhyme · 写词工作台

给新人说唱写手用的写词工具。第 1 期只做中文，全部在浏览器里运行，不需要账号，也不调用任何 AI 接口。

## 现在能做什么

- **找韵**：输入一个词，按单押、双押、三押、四押给出候选。只给词典里真实存在的词，生僻词默认隐藏。默认严格押（主要元音和韵尾都相同，忽略介音），“含宽押”要手动打开，结果里会标“宽”。不押或不是词的结果可以点 × 永久屏蔽。
- **韵脚检查**：在编辑器里写词或贴别人的歌词，押上的地方自动按组着色，侧栏列出每组押了几次、押韵密度，以及“像数来宝”“这句太长可能唱不顺”这类提醒。
- **唱法与字数**：选唱法和 BPM，得到每小节、每段主歌大约多少字。只做提醒，不拦你。
- **Beat 与打拍**：7 个按情绪分的示例 loop（浏览器实时合成）。在“打拍”页按空格记录节奏，落点对齐到 16 分音符，得到 `2-2-2` 这样的节奏码。
- **结构模板**：规整的段落模板可以随意改，草稿里用 `[主歌1]` 这样的标题分段，一行算一小节。
- **乐理卡**：7 张卡，每张一个概念，带可以点播的小示范和“我的归纳”笔记。

草稿、屏蔽的词、笔记都存在浏览器本地（localStorage），换浏览器或清除数据会丢，重要的词请另存一份。

## 运行

```bash
npm install
npm run dev      # 本地打开
npm test         # 押韵引擎和韵脚检查的测试
npm run build    # 产出 dist/
```

推送到 `main` 后会自动部署到 GitHub Pages（需要先在仓库 Settings → Pages 把 Source 设为 GitHub Actions）。

## 押韵规则

拼音由 [pinyin-pro](https://github.com/zh-lx/pinyin-pro) 标注，再拆成韵类，见 `src/lib/rhyme.ts`。

| 模式 | 规则 | 例子 |
| --- | --- | --- |
| 严格 | 主要元音 + 韵尾相同，忽略 i/u/ü 介音 | 一万 / 吸管 / 比惨；不错 / 渡过 |
| 含宽押 | 再合并 e 与 o、i 与 ü、en/in/eng/ing | 人犯 / 城管；不错 / 不可 |

## 词表

`public/data/zh-words.txt` 由 `scripts/build-words.mjs` 从 [jieba](https://github.com/fxsjy/jieba) 的词典（MIT 许可）生成：只保留 2 到 4 个字的词，按词频分成常见、一般、生僻三档，人名地名等专有名词不够常见的归入生僻。重新生成：

```bash
npm run words -- /path/to/jieba/dict.txt
```
