# Drum samples

These one-shot drum sounds come from the sample set bundled with Sonic Pi
(https://github.com/sonic-pi-net/sonic-pi/tree/dev/etc/samples). According to
that project's README they originate from freesound.org and are in the public
domain under Creative Commons 0 (https://creativecommons.org/publicdomain/zero/1.0/).

They were converted to mono 16-bit WAV and trimmed for use here.
